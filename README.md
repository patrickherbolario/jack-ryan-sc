# Jack Ryan 12-Week S&C Program

A PWA workout tracker built around Simon Waterson's approach.

## Deploy to GitHub Pages

1. Create a new repo at github.com named `jack-ryan-sc`
2. Upload all files in this folder to the repo
3. Go to repo Settings → Pages → Source: Deploy from branch → main → / (root)
4. Your app will be live at: `https://patrickherbolario.github.io/jack-ryan-sc/`

## Install as PWA on Pixel

1. Open Chrome on your Pixel
2. Navigate to `https://patrickherbolario.github.io/jack-ryan-sc/`
3. Tap the three-dot menu → "Add to Home screen"
4. Done — it installs like a native app and works offline

## Files

- `index.html` — the full app (single file, self-contained)
- `manifest.json` — PWA manifest
- `sw.js` — service worker for offline support
- `icon-192.png` / `icon-512.png` — app icons
- `.nojekyll` — required for GitHub Pages
